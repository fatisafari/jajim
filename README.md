# Jajim

A static HTML/CSS website.

## Run locally

From the project folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Main page

`index.html`

## Deployment

The repository includes a `CNAME` file for `jajim.co`. Keep it only when this repository is the GitHub Pages source for that domain.
